# TShock插件：禁NPC

> [!NOTE] 本文原载于 Bilibili 专栏
> [阅读原文](https://www.bilibili.com/read/cv16441641/) · 2022-05-04
> 成文较早，文中的版本号和命令可能已经过时，请结合实际情况判断。

有次和PE群的小伙伴，一起讨论下个坑的玩法，有聊到 禁NPC 和 禁合成，于是写了这个插件。

每隔2秒，检测世界里的NPC和物品，发现是在配置文件上的，就移除掉。

这个方案和粗暴，其实这个方案的灵感来自“第一分形”。

禁NPC没得说，NPC一生成就会被清掉，默认的检测时间是2秒，这个时长可以在配置文件里改。

禁合成，基本思路是把各种工作台给禁掉，并不是完完全全的禁合成，例如没法禁掉恶魔祭坛，一些徒手合成的物品，正常就可以获得，禁掉的话，就过头了。

其实这个插件3个月前就写好了，感觉差点意思就没发出来。最近发现这个插件还有其它用途，比如 有人玩爆炸兔上头，则可以把爆炸兔的NPC ID和物品ID，添加到配置里。

插件写很简单，也开源了，详细请看下项目地址：https://gitee.com/hufang360/TShockDisableNPC

插件 默认会禁 30种NPC 和 84个物品，最后 感谢一下 幻云 ，他帮我找了绝大多数的 物品ID。
