## 安装.net6.0运行时

运行时的英文是runtime，一般在下载时会遇到 xx-runtime 和 xx-sdk，一般sdk的文件比较大，安装这两个都是可以的。

我安装.net6.0的过程不像mono那么曲折，不过这当中也有一些坑。CentOS8 上面，通过yum安装的.net6.0不足以启动tshock，需要手动安装，下面是我摸索出来的最方便的安装方法，指令执行完后就可以了。

```bash
cd /usr/lib64/
mkdir dotnet
wget https://dotnetcli.azureedge.net/dotnet/Runtime/6.0.12/dotnet-runtime-6.0.12-linux-x64.tar.gz
tar -xvf dotnet-runtime-6.0.12-linux-x64.tar.gz
```

如果下载太慢，可以先在自己电脑上下载好，再长传。尝试提供一个镜像地址：

```bash
wget https://gitee.com/hufang360/tshock-mirror/releases/download/v5.1.3/dotnet-runtime-6.0.12-linux-x64.tar.gz
```

参考链接：https://learn.microsoft.com/zh-cn/dotnet/core/install/linux-scripted-manual#scripted-install

## 下载TShock


## 解压TShock

linux版本和windows版本不同，压缩了两次，打包成tar是为了保留了“TShock.Server”文件的可执行属性，免去了执行“Chmod +x TShock.Server”。
下面是解压指令：

```bash
unzip TShock-5.1.3-for-Terraria-1.4.4.9-linux-x64-Release.zip -d ./
tar -xvf TShock-Beta-linux-x64-Release.tar
```

## 启动TShock

这次tshock有了可执行文件，直接运行就好了。

```bash
./TShock.Server
```

运行命令后，按Ctrl+Z，退出运行。 可以看到目录下会多出一个名为tshock的目录，是不是有点眼熟，配置文件这部分tshock没变动。

![[cv20692064-04.webp]]

## 汉化TShock

这次TShock终于有汉化了，启动的时候加上“-lang 7”就好了

```bash
./TShock.Server -lang 7
```
