# 泰拉瑞亚：多人联机服务器搭建 Docker篇

> [!NOTE] 本文原载于 Bilibili 专栏
> [阅读原文](https://www.bilibili.com/read/cv44935835/) · 2026-01-21

几年前，我看到tshock的docker部署命令，是丈二和尚摸不着头脑，咋就开服了，我连开服文件都没看到😵。。。

docker好处也很明显，快速部署，多平台体验一致。之前tshock需要mono环境，后面需要.net6.0, 最近是 .net9.0，用docker开服则可以无视这些。之前还会遇到终端乱码，控制台吞指令情况，docker就没这个问题 ✨。

服务器内存最好4G，2G的很容易崩~。

docker像一首诗，寥寥几行，就搞定了复杂的部署过程，优雅，优雅！🪶

## 快速开服

```bash
docker run -it --name tshock \
  -p 7777:7777 \
  -p 7878:7777 \
  -v /root/S1/tshock/:/tshock \
  -v /root/S1/worlds/:/worlds \
  -v /root/S1/plugins/:/plugins \
  ghcr.io/pryaxis/tshock:latest \
  -world /worlds/world.wld \
  -lang 7 \
  -autocreate 3 \
  -difficulty 2
```

- -lang 7, 中文。
- -p 7777:7777, 冒号左边的 7777 是联机端口。
- -p 7878:7878, 可选，TShock REST API（Web 控制台）。
- -autocreate, 世界大小，1=小, 2=中, 3=大。
- -difficulty, 世界难度，0=普通, 1=专家, 2=大师, 3=旅行。
- -seed, 种子，例如 -seed 05162020 ，-seed skyblock。
- -worldevil, 腐化类型，random=随机，corrupt=腐化，crimson=猩红。例如 -worldevil corrupt 。
- -motd, 进服提示语，例如 -motd "欢迎来到我的泰拉!" 。

直接复制上面的命令，粘贴到终端上运行，下面这些操作都是自动进行的：

- 如果网络通畅，docker会从github上(ghcr.io)下载tshock镜像。镜像大概90mb，解压释放后在300mb左右。里面包含tshock以及运行环境。
- 紧接着会创建名为 tshock 的容器，容器起来后会自动创建世界。
- 开服文件在 /root/S1 目录下，可以按实际实际情况来。
- 要退出控制台，请先按 Ctrl+P，再按 Ctrl+Q 。服务器会在后台运行。直接按 Ctrl+C 会直接关闭容器。

## docker-compose

个人更喜欢用编排来创建docker，搭配1panel，就知道开服参数了，也不用从笔记软件里找docker run指令。

```yaml
# --- 常用操作 ---
#   进入控制台 : docker attach tshock
#   退出控制台 : 先按 Ctrl+P，再按 Ctrl+Q
#   查看日志: docker logs -f tshock
services:
  tshock:
    # 候选：latest 最新 / stable 稳定 / general-devel 开发 / 6.1.0 指定版本
    image: ghcr.io/pryaxis/tshock:latest
    container_name: tshock
    tty: true
    stdin_open: true
    environment:
      - TZ=Asia/Shanghai
    ports:
      - "7777:7777"     # 游戏联机端口
      - "7878:7878"     # TShock REST API（Web 控制台）
    volumes:
      - /root/S1/tshock:/tshock
      - /root/S1/worlds:/worlds
      - /root/S1/plugins:/plugins
    # --- command 参数 ---
    #   -lang 7              中文
    #   -pass xxx            密码
    #   -world xxx.wld       指定地图文件
    #   -autocreate 1|2|3    世界大小：1=小 2=中 3=大
    #   -difficulty 0|1|2|3  难度：0=普通 1=专家 2=大师 3=旅行
    #   -seed xxx            种子，不填则随机，skyblock / 05162021 / fortheworthy ...
    command: >  # 下面的这几行，行尾不能写注释，因为 # 后面的内容会变成参数
      -lang 7
      -world /worlds/world.wld
      -autocreate 3
      -difficulty 2
      -seed "skyblock"
```

下面是腐竹常见的操作：

```bash
# 查看日志
# - 按 Ctrl+C 退出查看
docker logs -f tshock

# 进入控制台
# - 看不到旧的日志
# - 先敲一个enter键，然后输入要执行的指令
# - 先按 Ctrl+P，再按 Ctrl+Q 退出
docker attach tshock
```

```bash
# 开服/关服/重启
# - 注意关服操作，是立即完成的，不会先保存地图
docker start tshock
docker stop tshock
docker restart tshock

# 删除容器
# - 先停止，再删除
# - /root/S1 不会随容器一起删除
docker stop tshock
docker rm tshock
```

```bash
# 进入容器终端
# - 一般用不到，进入容器内查看文件等
# - 执行 exit 命令退出容器终端
docker exec -u root -it tshock bash
```

## 更新

```bash
# 拉取/更新镜像
docker pull ghcr.io/pryaxis/tshock:latest

# 拉取/更新 测试版镜像
docker pull ghcr.io/pryaxis/tshock:general-devel

# 如果有新的，先把运行的容器删掉
# 然后再执行文章开头的 docker run 指令
docker stop tshock
docker rm tshock
```

## 强制开荒

切换到 `/root/S1/tshock/` 目录，修改这两个文件：

- 修改 sscconfig.json

```json
"Enabled": true,
```

- 修改 config.json

```json
"RequireLogin": true,
```

## 插件

- 推荐使用 快速开服+自动注册 插件，快速开启强制开荒，并为首次进服的人自动注册账号。

[泰拉瑞亚：多人联机服务器搭建 · 配置篇](https://www.bilibili.com/opus/510866706091531529)

- wm 插件，修改世界、种子、名称等。。

[TShock插件：WorldModify | 简易的世界修改器](https://www.bilibili.com/opus/527141367969642269)

- pm 插件，玩家管理，查背包、导出玩家存档等。。

[TShock插件：PlayerManager | 玩家管理](https://www.bilibili.com/opus/565451694569091175)

将下载得到的dll文件，拷贝到 /root/S1/plugins/ 目录下，然后重启容器。
