# vol26004.泰拉原版服务器

> [!NOTE] 本文原载于 Bilibili 专栏

1月28日凌晨：1.4.5已更新。  
tshock可能不会第一时间更新，先用原版开服  
```bash
#!/bin/bash

# 切换工作目录
cd "$(dirname "$0")"|| exit

ver=1450
targetDir=./$ver/Linux

# 下载
wget https://terraria.org/api/download/pc-dedicated-server/terraria-server-$ver.zip
unzip -o terraria-server-$ver.zip

# 启动
chmod +x "$targetDir"/TerrariaServer.bin.x86*
"$targetDir/TerrariaServer.bin.x86_64" \
  -lang 7 \
  -port 7777 \
  -pass tr \
  -world ./world.wld \
  -autocreate 3 \
  -difficulty 2 \
  -seed 05162021
```

-lang7, 中文  
-port, 联机端口  
-pass, 密码  
-autocreate, 世界大小，1=小, 2=中, 3=大。   
-difficulty, 世界难度，0=普通, 1=专家, 2=大师, 3=旅行。   
-seed, 种子。  
地图默认保存在 `/root/.local/share/Terraria/Worlds` 目录下  
后台运行  
```bash
# 列出会话
screen -ls

# 创建会话
screen -S tr

# 恢复会话
screen -r tr

# 控制台界面
# ctrl+A,ctrl+D 退出screen
# ctrl+c 关服
```
