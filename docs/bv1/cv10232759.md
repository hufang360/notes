# TShock指令：/sb, /sm（召唤BOSS、敌怪和NPC）

> [!NOTE] 本文原载于 Bilibili 专栏
> [阅读原文](https://www.bilibili.com/read/cv10232759/) · 2021-03-11
> 成文较早，文中的版本号和命令可能已经过时，请结合实际情况判断。

\*本文仅面向服主

sb 和 sm 指令，可以用来做测试（zhenghuo）。

![[cv10232759-01.webp]]

游戏中的敌怪、BOSS、NPC 和 小动物 都可以使用sm来召唤，sb却只能召唤一些特定BOSS。sb在召唤时，且会创造一些条件。

例如：使用/sb指令召唤 克眼（克苏鲁之眼），会先将服务器时间调整到晚上，然后执行召唤NPC指令，而/sm指令则是直接召唤 克眼，如果实在白天召唤，克眼则会脱战。

仅当启动服务器时传入`-lang 7`参数时，sm指令才能识别NPC的中文名。

```bash
mono "./tshock-client/TerrariaServer.exe" \
 -world "world.wld" \
 -lang 7
```

## sb指令

\*tshock各版本会有所差异，以下整理自tshock v4.4.0的源码。

```bash
# 全明星阵容
# 召唤boss，并将时间调到晚上（19:30）：
# 史莱姆王、克苏鲁之眼、克苏鲁之脑、世界吞噬怪、蜂王、骷髅王
# 双子魔眼、毁灭者、机械骷髅王、史莱姆皇后、世纪之花、石巨人、光之女皇、猪龙鱼公爵、拜月教邪教徒、月亮领主
# 不包括 血肉墙，因为ta需要在地狱召唤
/sb all

# 史莱姆王，可召唤多只
# 下面3个指令功能一样
/sb "king slime"
/sb king
/sb ks

# 克苏鲁之眼，，可召唤多只，时间会调到晚上
/sb "eye of cthulhu"
/sb eye
/sb eoc

# 鹿角怪（需要tshock v4.5.6）
/sb deerclops

# 世界吞噬怪，可召唤多只，不在 腐化之地，BOSS会脱战
/sb "eater of worlds"
/sb eow
/sb eater

# 克苏鲁之脑，可召唤多只，不在 猩红之地，BOSS会脱战
/sb "brain of cthulhu"
/sb boc
/sb brain

# 蜂王
/sb "queen bee"
/sb qb

# 骷髅王
# 时间会调到晚上，白天召唤，不会脱战，但会变得像地牢守卫一样，转动头部并对玩家造成巨大伤害。
/sb skeletron

# 血肉墙（肉山），须在地狱
/sb "wall of flesh"
/sb wof

# 史莱姆皇后
/sb "queen slime"
/sb qs

# 机械骷髅王
/sb "skeletron prime"
/sb prime

# 双子魔眼，时间会调到晚上，并同时召唤 激光眼 和 魔焰眼。
/sb twins

# 毁灭者，时间会调到晚上。
/sb destroyer

# 世纪之花
/sb plantera

# 石巨人
/sb golem

# 光之女皇，不会将时间调到晚上。
/sb "empress of light"
/sb empress
/sb eol

# 猪龙鱼公爵（猪鲨）
/sb "duke fishron"
/sb duke
/sb fishron

# 拜月教邪教徒，可召唤多个。
/sb "lunatic cultist"
/sb lunatic
/sb cultist
/sb lc

# 天界柱 可召唤多个，玩家死亡不脱战。
# 下面指令依次对应 日耀柱、星旋柱、星云柱、星尘柱
/sb "solar pillar"
/sb "vortex pillar"
/sb "nebula pillar"
/sb "stardust pillar"

# 月亮领主，可以召唤多个。
/sb "moon lord"
/sb moon
/sb ml

# 哀木，不会将时间调到晚上，白天会脱战。
/sb "mourning wood"

# 南瓜王，不会将时间调到晚上，白天会脱战。
/sb pumpking

# 常绿尖叫怪，不会将时间调到晚上，白天会脱战。
/sb everscream

# 冰雪女王，不会将时间调到晚上，白天会脱战。
/sb "ice queen"

# 圣诞坦克，不会将时间调到晚上，白天会脱战。
/sb santa-nk1
/sb santa

# 荷兰飞盗船（海盗船），可召唤多艘。
/sb "flying dutchman"
/sb flying
/sb dutchman

# 火星飞碟，经测试目前无法召唤，不过可以通过指令召唤一次火星人入侵。
/sb "martian saucer"
/worldevent invasion martians

# 双足翼龙，可召唤多只，玩家死亡不脱战。
/sb betsy
```

## 清除召唤

召唤了，打不过怎么办？

```bash
# 清除附近的NPC，包括城镇NPC
# 可以指定清除半径
/clear npc
/clear npc 100

# 将所有NPC杀死（屠杀），包括城镇NPC，BOSS死亡时会掉落物品，芜湖。。。
/butcher
```
