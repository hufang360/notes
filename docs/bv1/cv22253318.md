# TShock插件：指令晶塔v1.1

> 成文较早，文中的版本号和命令可能已经过时，请结合实际情况判断。

一直在尝试，解除晶塔的限制，之前写了晶塔插件的1.0版本，解决了村民不够多，打boss时不能传的问题。这次找到了放置晶塔的方法，于是就有了1.1版本。

> 参考：[Bilibili 专栏 cv431811850](https://www.bilibili.com/read/cv431811850/)

## 第一部分

输入“/pylon place 森林”指令，就会在你脚下放置一个森林晶塔。

![[cv22253318-01.webp]]

指令可以**放置1个以上的相同类型的晶塔**。

![[cv22253318-02.webp]]

为了保证安全，会检查周围3x4区域是否为空，以及脚下3x1区域是否有方块，如果不满足条件则会提示你前往空地进行放置。

另外执行“/pylon place”指令需要“pylon.place”权限，使用pylon指令传送的权限名是“pylon”，其实这个指令就是给服主准备的，当然你也可以把这个配到鱼店里面，让玩家用钱买或者用晶塔换。

![[cv22253318-03.webp]]

## 第二部分

新增了“/pylon **fix**”指令，目前可以修复这样一种错误。

图格没了，但在小地图上晶塔图标还在，图标是灰色的，而且无法正常使用，还会占用晶塔位，让你无法放置第2个同类型的晶塔。

下图所示，图片的上部分是用指令放置了7个晶塔。图片的下部分是使用一些指令清除了图格，图格没了，但是晶塔数据还在，而且重开服依旧。

![[cv22253318-04.webp]]
