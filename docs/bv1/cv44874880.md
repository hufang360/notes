1.4.4.9最新开服笔记。  
1.4.5 临近！方便到时候快速开服！  
平台：linux（debian12 / CentOS8）  
版本：TShock 5.2.4 for Terraria 1.4.4.9  
备注：  
写得很简略，假设你已经是一位成熟的腐竹，只是不记得地址而已。  
最原始的开服方法，古法开服，第一时间能用上新版tshock。2核2G也能开服玩。  
还会再写一篇docker的开服笔记，等我捋一捋~  
下载.net6.0  
我是放到 /root/dotnet 目录下，然后在开服脚本指明路径。  
```bash
cd /root
mkdir dotnet
cd dotnet
wget https://dotnetcli.azureedge.net/dotnet/Runtime/6.0.36/dotnet-runtime-6.0.36-linux-x64.tar.gz
tar -xzvf dotnet-runtime-6.0.36-linux-x64.tar.gz
```

下载tshock  
我是放到 /root/tshock 目录下，之后每开一个新档，就复制一份这个目录。  
```bash
cd /root
mkdir tshock
cd tshock
wget -O ./TShock.zip https://github.com/Pryaxis/TShock/releases/download/v5.2.4/TShock-5.2.4-for-Terraria-1.4.4.9-linux-amd64-Release.zip
# 解压
unzip TShock.zip
tar -xvf TShock-Beta-linux-x64-Release.tar
# 清理
rm TShock.Installer TShock-Beta-linux-x64-Release.tar TShock.zip
```

开服脚本  
运行下面的命令，创建 /root/tshock/run.sh 开服脚本。  
```bash
cd /root
cd tshock

# 快速将命令写入到脚本里
cat > run.sh << 'EOF'
#!/bin/bash

# finalshell 不乱码
# LANG="en_US.UTF-8"

# dotnet环境变量
export DOTNET_ROOT=/root/dotnet/
export PATH=$PATH:$DOTNET_ROOT:$DOTNET_ROOT/tools

# 切换工作目录
sh_path=$(cd `dirname $0`; pwd)
cd "$sh_path"

# 启动tshock
./TShock.Server -world world.wld -lang 7
EOF

# 设置脚为可执行
chmod +x run.sh
```

开新档  
S1 就是 Serve1 的意思，表示第一个档，第二档就是S2  
```bash
cd /root
cp -rf tshock S1
cd S1
./run.sh
screen
```

一直用screen，换tmux也行，目的是让泰拉能在后台运行。  
```bash
# 安装screen

# debian
apt install screen

# centos
yum install screen
# 创建一个会话
screen -S S1

# 进入上次的会话
screen -r S1

# 查看以创建的会话
screen -ls

# 退出会话
# 按 ctrl + a，然后再按 d
```

插件  
私心，这里有我个人常用的开服插件：  
https://github.com/hufang360/iTShock  
FastDeploy.dll，快速开服插件，控制台输入 /fd init 开启强制开荒。  
AutoRegister.dll，自动注册插件。  
WorldModify.dll，世界管理，开关彩蛋种子，查看boss进度等，输入 /wm help 查询使用说明。  
PlayerManager.dll，玩家存档管理，查背包，备份/导出人物存档，输入 /pm help 查询使用说明。  
NoVersionLimit.dll，允许不同版本的泰拉进行联机。手机+国际版+汉化玩家可能没法第一时间更新，这个插件允许他们进服来玩，但是看不到新道具，也不要把新道具给他们，会消失的。再有就是版本不同可能会有闪退问题。
