## worldinfo

**worldinfo**，一看就知道可以用它来查看世界（地图）信息，在游戏里和控制台上都能使用。它可以显示 世界名字、尺寸、种子和ID。

Size 表示 世界大小：

小型世界 4200×1200 格

中型世界 6400×1800 格

大型世界 8400×2400 格

![[cmd-worldinfo-02.webp]]

## worldmode

**worldmode**，亦如其名，它跟世界模式（难度）有关，只不过它是修改世界模式，而不能查询。

模式共4种，分别是 经典、专家、大师、旅行，大师的难度相当于经典的3倍，专家是2倍，旅行是0.5倍。此外旅行模式下还可以随时调整难度。
