先汇报下这次更新的主要功能——搬家。

世界重建前会扫描基地放置的箱子和放置物，然后放到新家的箱子里，提示重建时会给出一个搬家清单，像下图这样：

![[quake-v11-01.webp]]

搬家清单可以输入 /quake report 实时查看，注意这个只是当前的，重建前可能还会有变化。

## 搬箱子

能搬的有两大类，一类是存放物品的箱子，另一类是放置的制作站这些。

那些**有名字的有物品的**箱子会搬迁到新家。NPC小旅馆的平台上会放置箱子，只在旅馆的一楼，最多12个箱子，如果要搬的箱子太多，则会在出生点3格高的地方新建一行平台来放箱子。如果你配置了不生成小旅馆，那所有的箱子就放在这一行平台上。

![[quake-v11-02.webp]]

小概率地会出现箱子放置失败的情况，用 /quake ic 指令能快速导入失败的最后一个箱子。两个或更多的箱子呢，箱子和里面的物品会保存在 record.json 复制，复制 item里面的内容粘贴到 tshock/quake/chest.txt 后，然后输入 /quake ic 指令导入，chest.txt 只有一行的哦。

![[quake-v11-03.webp]]

## 搬制作站

放置的物块、墙、平台、制作站、家具等，计划是尽可能地都支持，但工作量太大，不少处理起来很费时间，目前还有不少家具不支持，目前可以搬这些：

-   绝大多数玩家放置的方块、墙、平台 和 种植盆（会收获种植盆上面 成熟的草药） ；
-   绝大多数玩家放置的1x1的东西；
-   全部的制作站；
-   4种银行类家具；
-   10种buff类家具；
-   物品框及上面的物品；
-   武器架及上面的武器；
-   附魔日晷、丛林蜥蜴祭坛；
-   其它变装家具，工作台、篝火、圣物、雕像、旗帜、传送晶塔等等；

![[quake-v11-05.webp]]

## 扫描范围

基地就是出生点附近的一屏区域，默认的扫描区域有电脑版一个屏幕大小，约122格宽，68格高。备注只有传送晶塔是全图扫描。

由于基地一般是出生点往上建，所以扫描区域往上挪了26格，大概是你站在NPC小旅馆2楼的楼顶位置，所看到的东西。另外这个区域是支持调整，改配置文件就行。

## 地图信息（备份/恢复）

这次把世界信息保存到 record.json 文件里。

输入 /quake backup 可以将地图信息保存到 record.json 。

输入 /quake report 会报告搬家清单。

输入 /quake recover 可以恢复信息到当前世界，恢复boss进度、箱子、活着的NPC、怪物图鉴、搬的制作站。

![[quake-v11-10.webp]]

配置文件中 chests 部分是基地箱子和里面的物品，pylons 是晶塔，extras 是制作站这些。

npcs是当时地图活着的NPC。

kills、sights、chats 是怪物图鉴记录。

## 地狱直通车

个人喜欢挖这种3格宽，中间一根绳索的地域直通车。开启创建地狱直通车后，且击败骷髅王后就会重建一条通往地狱的直通车。

这部分功能代码参考了 worldrefill 这个插件。

## 配置文件

1.1版的文件有点不一样。

```json
{
  "seeds": [
    "5162021",
    "for the worthy",
    "not the bees",
    "constant"
  ],
  "quakeDelay": 40,
  "size": 0,
  "keepFTW": true,
  "keepNTB": true,
  "keepDST": false,
  "keep2020": false,
  "keep2021": true,
  "kickGen": false,
  "successTips": "[i:3611]输入 /wi 查看 世界信息\n[i:149]输入 /bi 查看 boss进度",
  "autoCreateRoom": true,
  "autoCreateHellevator": true,
  "area": {
    "X": -61,
    "Y": -60,
    "Width": 122,
    "Height": 68
  }
}
```

删除了 freezePlayer 和 freezeBuffs，这次取消了 全员禁足 功能，不过重建世界时还是会把玩家都传回出生点，重建世界时会把刷怪量调成0，重建完后恢复。主要是因为上个版本全员禁足，导致被幻灵sha疯了。。

kickGen，重建世界时踢出玩家，这个功能主要是考虑到 有时创建的地图会支离破碎，踢出稳定性会好点，大概吧，主要是个人心理上。还有一点是重建世界要同步很多信息，可能会在短时间收发超多的网络消息，踢出玩家可以节约流量~具体情况还没认真测试和计量。

quakeDelay，默认打完boss后有30s的时间用来捡宝藏袋，有时打boss挂了，回宝藏袋掉落点又来不及，则需要适当延长大地动到来的时间，索性把这个写到配置文件里。

autoCreateHellevator，自动创建地狱直通车。

area，搬家扫描区域，x和y是相对于出生点的相对位置。
