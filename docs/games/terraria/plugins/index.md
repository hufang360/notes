陆陆续续地，写了好些插件，10月TShock更新到5.x版本，和很多插件一样，我写的大部分插件也不能用了，精力有限，我只“适配”了我常用的，自动注册、鱼店、wm 和 pm这几个插件。

前段时间，有人私信说，你能不能更新下你的所有插件~~瞬间血压高~~~~，不可否认，我恼的情绪中，确实有懒的成分。有些代码过了一段时间已经不太记得了，需要花时间去熟悉，改完了还要去测试，有时候会感觉以前写的可以优化一下，这个就更花时间了。有些插件，我则是弃坑了。而且我也不认为他会去用我的所有的插件，有点贪心，能用2~3款就不错了，毕竟之前遇到有些人，连我写的说明文档不看的，就知道问，宁愿一个问题问3天，也不愿意自己去查下说明文档，或者自己去实践下。

写插件，主要是满足我自己的开服需要，之后才是考虑有更多腐竹可能跟我一样有这个需要，就发出来，插件也都是无偿提供的，因为绝大多数tshock插件都是开源的，那我也开源一下，也希望tshock圈越来越好，越来越繁荣，退一步讲，回头我退坑了，有能力的也好拿去修改。

写插件也是件“孤独”的事情，有时插件写复杂了容易出问题，希望有人提建议反馈他遇到的问题，可能因为TShock服主圈较小，正好又是有在用就更少的。再说，之前收到的一些反馈，我也不一样认同，有的能力达不到，有的则是tshock做不到。总之，自产自销，自娱自乐吧。

后面有人想用“大地动”插件，在插件群问有没有人帮忙适配，也没人回，前后也问了我两次，看来是真的需要，这个插件的适配，大概只需重新编译一下，可以适配下。适配完了发现，之前大地动后搬家操作会丢箱子可以尝试一个新方法解决，算了，还有好几个坑要填，先放着~

今天我抽了些时间整理了下我写过的插件，顺便适配了几个，由于代码都在码云上面，就把内容放码云上了，请移步：https://gitee.com/hufang360/trcommon/blob/master/TShock.md
