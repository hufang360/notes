# 关于1.4.2汉化小错误

> [!NOTE] 本文原载于 Bilibili 专栏
> [阅读原文](https://www.bilibili.com/read/cv10651716/) · 2021-04-06
> 成文较早，文中的版本号和命令可能已经过时，请结合实际情况判断。

玩游戏发现1.4.2中 蓝玉叫萨菲，红玉叫鲁比，ruby我知道就是红宝石的意思，真就音译呗！

对照发现，大概有这些出入：

**红玉** 翻译成了 **鲁比**，英文是 Ruby

**蓝玉** 翻译成了 **萨菲**，英文是 Sapphire

物品词缀 **轻** 翻译成了 **莱特**，英文是 Light

**钴** 翻译成了 **寇伯特**，英文是 Cobalt

**尖刺** 翻译成了 **斯派克**，英文是 Spike

**冬青树** 翻译成了 **霍利**，英文是 Holly

**云** 翻译成了 **克劳德**，英文是 Cloud

**暴风雨**  翻译成了 **斯托姆**，英文是 Storm

随机世界名中的 **夜晚** 翻译成了 奈特，英文是 Night，当然这个不太重要

跟 **子弹** 相关的射弹都被翻译成了 **比莱**，英文是 Bullet

1.4.2新支持 **语言包**，针对这些翻译出入做了一个资源包
