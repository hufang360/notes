## 1.4.3.4

1.4.3.4 修复了 1.4.3.3 的一些严重问题。

修正了游戏中游戏摇杆和鼠标输入的特定组合导致 Steam Deck 上出现光标式闪烁的问题。

修正了特定的游戏摇杆 UI 操作无法正常执行的问题。

## 1.4.3.3

1.4.3.3 主要提供了对 Steam Deck 的优化、数个平衡性调整和 Bug 修复。

**总体**

-   召唤的仆从、哨兵、及其射弹不再伤害小动物
-   更新了气球束的外观，以更好的展现用于合成它的物品
-   当在天然墙旁边放置在墓地制作的对应墙时，它们现在应当无缝衔接，不会有较大空隙
-   骷髅王现在会掉落治疗药水而非弱效治疗药水。鹿角怪的掉落同样如此，但蜂王仍会掉落蜂蜜瓶。
-   小雪怪皮毛在旅行模式中完成研究所需数量更少
-   所有食物（麦芽酒和清酒除外）在旅行模式中完成研究所需数量更少
-   所有生物群落宝匣，以及金锁盒和黑曜石锁盒在旅行模式中完成研究所需数量更少
-   黑珍珠和粉珍珠在打开牡蛎时更为常见。它们的出售价值也按比例降低了
-   黑曜石现在可被具有 55% 镐力及以上的镐采掘
-   现在在经典模式中击败血肉墙时总是会掉落 1 件武器和 1 件徽章，和专家宝藏袋一样
-   心形雕像和星星雕像现在相较于其他雕像的生成几率提高到两倍
-   蛛丝吊索的射程增加 25%
-   食人鱼枪的食人鱼现在能够更好地跟随快速移动的敌怪，只要它们没有传送或是短暂变为无敌
-   将仙灵之翼的配方改为仅需 99 个妖精尘，而非 100（因为妖精尘的最大堆叠数为 99）
-   相较于用于制作它的宝石，花窗玻璃的售价更加合理
-   优化了放置沙漠箱阶段的世界生成
-   虚拟键盘（供手柄使用的游戏内键盘）现在可用于 IP /密码输入，以及其他的多人模式文本输入

**鹿角怪**

-   现在如果玩家还未击败鹿角怪，向导会提供一条如何寻找它的提示
-   现在鹿角怪的生命在专家和大师模式下会和其他 Boss 一样根据修改过的系数增加。因此，它的最大生命在专家和大师中都会降低。
-   上述修复也修正了鹿角怪的生命在专家/大师多人模式中没有按玩家数提高的问题
-   现在在附近没有玩家时，鹿角怪只会在雪原生物群落中停留 1 天而非 3 天
-   鹿角怪的 Boss 生命条现在会在距离远到 Boss 战不激活时消失。其Boss 生命条会在战斗继续时重新出现
-   修复了鹿角怪具有 0 防御的疏漏
-   在击败鹿角怪时，它在适当条件下只有 25% 的几率自然生成，而非之前的 100%
-   鹿角怪现在在死亡时掉落药水：和骷髅王一样为治疗药水

**NPC 快乐**

-   现在晶塔最少需要 2 个 NPC 才会售卖
-   NPC 能够售卖晶塔的最低快乐由 0.85 降低至 0.9（数字越低，快乐越高）。这意味着让 NPC 足够快乐到能够售卖晶塔更加容易
-   如果 NPC 在混合生物群落中（如神圣沙漠），且他至少喜欢这些生物群落中的一个，则他将会从他喜欢的生物群落中获得快乐加成。这仅会在处于喜欢的生物群落与中立/不喜欢的生物群落中时生效；这不会使得中立生物群落覆盖不喜欢的生物群落；这也不会覆盖由于邻近腐化之地、猩红、或地牢而导致的最大不快乐/房屋不可用。
-   在“拥挤”惩罚生效前，城镇中能够生活的 NPC 的最高数量提升了 1 个

**Bug 修复**

-   修复了玩家在睡眠时，眼球伞的云的位置奇怪的问题
-   修复了应当阻挡光的一些物块没有阻挡光的问题
-   修复了蜂蜜炸弹和干炸弹不能放置在武器架上的问题
-   修复了来自腐化火把的火把神的射弹生成雪原尘的问题
-   修复了切斯特的智能光标边框在他处于空中时不随他旋转的问题
-   修复了行走的金鱼无法像其他金鱼一样变为腐化/猩红的问题
-   修复了沙漠虎在旅行模式时间设置为暂停或加速时无法正确地在敌怪上弹跳的问题
-   修复了熔岩钓鱼的装备会错误地影响钓鱼时间的 Bug
-   修复了黑曜石盔甲虽然在其等级应当具有更高的稀有度，却只具有 白色 的稀有度的问题
-   修复了露西斧在砍伐棕榈树或仙人掌时不会说话的问题
-   修复了与丛林神龛和生命红木树重叠生成可能会产生破损的宝箱的问题
-   修复了星星斗篷类配饰生成的星星在多人模式下不正确同步的问题
-   修复了世纪之花的孢子射弹在多人模式下不正确同步的问题
-   修复了带电减益具有不准确且毫无提示作用的工具提示的问题
-   修复了导致精灵熔枪每次使用消耗 2 发弹药的问题
-   修复了铁链血滴子的锁链在某些角度下消失的问题
-   修复了部分 UI 控制文本在波兰语语言设置下损坏的问题
-   修复了文本导致的多人模式崩溃
-   修复了特定 NPC 大量生成时罕见的崩溃
