# 揭秘“图格动画”

> [!NOTE] 本文原载于 Bilibili 专栏
> [阅读原文](https://www.bilibili.com/read/cv28775333/) · 2023-12-25
> 成文较早，文中的版本号和命令可能已经过时，请结合实际情况判断。

有人以为是我手动铺好方块，然后一帧一帧截的图。它其实是一个tshock插件，插件会读取txt，一个由120列68行组成的txt，里面只会是0或者1，0表示要放土块，1表示空白，插件会根据行列信息，把方块铺出来。1秒钟读取5个这样的txt，集中铺5次，就形成了动画。对视频知识了解的小伙伴知道，很多视频都是每秒25帧的，你这个插件1秒只有5帧，是不是太慢了点。诶，对，受限于性能目前在我电脑上1秒5帧不会出现卡顿，然后在剪辑的时候，进行加速，就变成大家看到的样子。

![[tile-animation-01.webp]]

**为什么不做成彩色的？**

虽然泰拉里面有很多种图格，但是能用于组成色彩的很少，很久之前我就想过，借助TEdit的图片转图格功能，将可达鸭跳舞变成动画，结果转出来的鸭子很雷人。

![[tile-animation-02.webp]]

直到有一天我看到这期视频，点开视频简介里面的github链接，看到作者的制作思路，然后安装XnConvert试了下，恍然大悟，彩色很难，黑白就要简单很多。

https://www.bilibili.com/video/BV1BC4y1g7dm

![[tile-animation-03.webp]]

XnConvert的动作里面选择“改变颜色深度”，选择“二进制”（只有两种颜色），由于插件只能识别0和1，图片必须只有黑白这两种颜色。

![[tile-animation-04.webp]]

![[tile-animation-05.webp]]

图片处理完成后，再使用python脚本将图片转成只有0和1组成的txt。

![[tile-animation-06.webp]]

![[tile-animation-07.webp]]

期间刷到全彩色版的《Bad Apple》，为了让视频表现更丰富，想到播放到指定画面时更换图格，红宝石块、彩虹砖、粉地牢砖、活火块等。

**“出道即巅峰”**

得益于《Bad Apple》动画实在做得太好了，那期视频的效果还不错。后面想尝试拿一些热梗做素材。

不像《Bad Apple》，其它的画面处理后有不同程度的瑕疵，批处理之后，需要手动逐帧去修图。哼哧哼哧，处理几十张后，发现效果不理想，又得重来，重来效果也好不到哪里去。。。

其实还有几个其它玩法，有一个是在指定帧的时候释放弹力巨石，模拟蓝球弹跳的动作（无端），其它玩法，由于视频还没出先保密。

![[tile-animation-15.webp]]

**四联屏**

由于电脑版的最大可视范围大约为 120x68格，因此图格动画的分辨率实际只有120x68px。为了展示更多细节，想到用四个屏幕来组成更大的画面，获得更多画面细节。哈哈，“出城剿匪”这段仿佛能看到师爷“声泪俱下”的样子。

![[tile-animation-16.webp]]

![[tile-animation-17.webp]]

说得这里，就显得很无趣了。制作一起视频还挺不容易的，一步不理想就要返工重来。更多的时间花在处理图片上。泰拉的部分越来越少。

插件主要是为了做视频用，图格动画的播放中心点其实是出生点，敲错指令100%毁家，而且播放过程中卡顿也挺明显的，挺吃服务器资源的，前不久刚用服务器试了下，资源占用达到一个新的高度。最后如果有超过10个人想要这个插件，我可以把它放到github上。
