# 泰拉瑞亚：钻头矿车！？

> [!NOTE] 本文原载于 Bilibili 专栏
> [阅读原文](https://www.bilibili.com/read/cv7075812/) · 2020-08-07

翻游戏美术资源时，发现钻头的矿车Sprite图，钻头不是坐骑么，难不成还有“钻头矿车”。

答案是**否定的**。

**钻头控制装置** 简称DCU（Drill Containment Unit），矿车相关的贴图是 “Mount\_Drill.png”、“Mount\_DrillFront.png” 。

召唤钻头坐骑后，在游戏左上角会显示“钻头坐骑”增益图标，图标上的钻头的跟“Mount\_DrillFront.png” 相同。

![[drill-minecart-01.gif]]

*贴图分解*

钻头坐骑、钻头、钻头，“钻头”去哪儿！？

要知道：

1、钻头坐骑，可以无限飞行；

2、镐力能达到 210%；

3、挖洞时，洞壁的方块会根据情况改变形态，保持洞壁平滑；

4、合成一个DCU非常不容易，需要共160块夜明矿(至少击败月亮领主两次才凑出)，720块叶绿矿，600个发光蘑菇，20个灵气，120块狱石矿石与陨石矿石，以及40块黑曜石；

**如此利器，必是外星科技**，怎么能有轮子，怎么能有钻头~

![[drill-minecart-02.gif]]

*使用钻头坐骑进行挖矿（图片来自官方wiki）*

在1.3版本中，加入了 DCU 、木矿车、铁矿车、机械火车，在游戏设定中，坐骑和矿车是共用一套“Mount\_IDs”（坐骑ID）。

在1.4版本中，新增了22种矿车，其中“鼹鼠矿车”也具备了挖掘能力。
