# Starbound汉化、自定义字体

> [!NOTE] 本文原载于 Bilibili 专栏
> [阅读原文](https://www.bilibili.com/read/cv9247853/) · 2021-01-12
> 成文较早，文中的版本号和命令可能已经过时，请结合实际情况判断。

Starbound，还没有官方中文名，我一般是叫“星界边境”，有人叫“星际边界”，也有人戏称为“屎大棒”。目前Starbound只有英语这一种语言，汉化一下才能有良好的体验，这里我推荐使用“星核汉化组”的汉化mod，安装方法是非常简单。

## 订阅汉化mod

1、访问**Starbound**的创意工坊；

![[chinese-font-01.webp]]

2、搜索**“星核”**，在搜索结果里找到“星核汉化组 简体中文”，并点击；

![[chinese-font-02.webp]]

3、点击订阅按钮安装汉化mod；

![[chinese-font-03.webp]]

4、汉化mod安装后，直接启动游戏，界面会出现很多长方形的框框，其实mod安装成功了，但是缺少字体。

![[chinese-font-04.webp]]

## 字体mod

1、下载字体mod

也可以直接从这个地址下载：https://cdn.jsdelivr.net/gh/sffxzzp/Starbound-Chinese@fonts/StarCore/StarCore.pak

![[chinese-font-05.webp]]

2、找到mods目录下,mods目录的查找方法见下图；

默认情况下是这个目录：C:\\Program Files (x86)\\Steam\\steamapps\\common\\**Starbound\\mods**

![[chinese-font-06.webp]]

3、拷贝pak文件到mods目录下

![[chinese-font-07.webp]]

下载和拷贝完mod后要重启下游戏，汉化成功后是下图的样子

![[chinese-font-08.webp]]

## 自定义字体

汉化mod还支持 ttf 格式的字体，让自定义字体变得很轻松。

1、将字体命名成 **hobo.ttf**；

2、在mods目录下新建 **font** 目录；

3、拷贝 hobo.ttf 到 font目录下；

放置好字体后，重启游戏即生效。实际测试发现 otf，ttc强行改成ttf也能生效。

个人喜欢使用“方正粗圆简体”作为游戏字体，看上即圆润，又清晰；
