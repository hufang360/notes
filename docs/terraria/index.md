# 泰拉瑞亚

TL Pro 是安卓上的泰拉瑞亚启动器，可以用它加载材质包。
这两篇讲怎么**做**材质包、以及怎么把电脑版的材质包**转**成 TL 能用的。

- [[cv11828472|TL Pro 材质包制作指北]] · 2021-06 —— 材质包的结构，和电脑版的异同
- [[cv11851664|TL 材质包转换小工具]] · 2021-06 —— 把创意工坊的材质包转成手机能用的
