# TL 材质包转换小工具

TL官方有发布了一个app，来打包材质包，打包！？很多手机党都没有电脑，操作只能在手机上完成，而且TL里面的材质包也不多，目前steam创意工坊上已超过1.6万个内容，如果能将电脑版的材质包转换成tl的材质包，岂不美哉！于是写了这个小工具。

> 参考：[Bilibili 专栏 cv11828472](https://www.bilibili.com/read/cv11828472/)

工具目前只能处理材质和音乐这两种类型。

1、首先选择一个材质包文件夹，该文件夹会有 icon.png和pack.json这两个文件。

材质包一般可以在这两个目录下找到：

存档目录：%USERPROFILE%\\Documents\\My Games\\Terraria\\ResourcePacks

创意工坊：C:\\Program Files (x86)\\Steam\\steamapps\\workshop\\content\\105600

2、选择导出目录，默认会导出到桌面，转换后桌面会多出一个以材质包名称命名的文件夹，复制这个文件夹到手机上就可以用了。

3、选择完成后，点击“开始”按钮

![[cv11851664-01.webp]]

工具如遇到.wav和.ogg文件会自动转码成.mp3，xnb格式暂不支持。

在导出目录下能找到转换日志，上面有文件名和数字的对照，以及哪些文件未处理等情况。

由于电脑版的材质包中不包含预览图和作者头像等信息，如果你想补充这些信息，则需要手动操作一下。
