# 达芬奇支持lottie动画了

> [!NOTE] 本文原载于 Bilibili 专栏
> [阅读原文](https://www.bilibili.com/read/cv50725252/) · 2026-06-20
> 成文较早，文中的版本号和命令可能已经过时，请结合实际情况判断。

继支持gif后，最近又支持lottie动画了。 lottie是啥呢！手机app想要加载一些丝滑的小动画，一般会用到它。比如 你下载一个哔哩哔哩的安卓安装包，将apk改成zip，然后解压，搜\`.json\`格式的文件，就能找到一键三连的lottie动画。又比如qq的超级表情也是lottie动画。 一般呢这些动作是用ae制作，使用lottie插件导出为.json格式的动画文件，这种动画有很多特点： 1、高清，大多数是矢量图形，可以放大很多倍也不会模糊。 2、流畅，不像gif，lottie动画非常丝滑 缺点呢： 1、目前知道的人还比较少，更别说普及了。 2、一般是一些几何动画/动效。 https://lottiefiles.com/ 上有大量的lottie动画 达芬奇这个features，我真的是爱死了~直接拖到时间轴上就可以了，另外lottie跟gif类似时长超短但是是那种无限循环那种的，此时先不要着急一直复制粘贴进行延长，在右侧的属性面板勾选 Ograf的loop即可，你可以自由拖拽长度，动画会自动循环。 关于版本： 我用的是DaVinci Resolve，对是免费版，不是付费的studio版本，也支持的哦！ 我的电脑是mac，有个小插曲，我从达芬奇官网下载的是 21 build 48，目前从appstore上下载的是21 build 20，不支持是appstore限制呢，还是说版本低了一点，没法直接导出，换成官网版本就好了。
