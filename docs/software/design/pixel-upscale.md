# 如何放大像素图？

> [!NOTE] 本文原载于 Bilibili 专栏
> [阅读原文](https://www.bilibili.com/read/cv6891040/) · 2020-07-24

众所周知，《泰拉瑞亚》是一款像素风游戏，有小伙伴说它是像素艺术，这点我很认同，从开始的无感到500小时游戏时间~

做视频时发现素材图分辨率太小了，很多都是 30px 左右，做图那就得放大，一放大画面就模糊了。

效果1：

![[pixel-upscale-01.webp]]

*史莱姆王子*

这时可以用ps来处理图片放大

-   打开图片后，执行“**图像**”-->“**图像大小**”
-   输入要缩放到的宽和高
-   点击 **重新采样** 下拉框，选择“邻近(硬边缘)”

操作动图演示：

![[pixel-upscale-02.gif]]

*ps缩放*

ps处理后的效果2：

![[pixel-upscale-03.webp]]

*史莱姆王子*

一般视频是1920x1080分辨率，像上面的史莱姆王子原图是36x36px，先用ps放大10倍（360x360px），导出png，作图和做视频都用刚刚导出的png，就可以解决模糊的问题了。
