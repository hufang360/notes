# 【动态】关于“永夜玩法”

> [!NOTE] 本文原载于 Bilibili 专栏
> [阅读原文](https://www.bilibili.com/read/cv12251005/) · 2021-07-21

看起来大家对永夜这个玩法有点感兴趣。“永夜”这个想法来自永夜之刃，我觉得永夜不是一直是夜晚，他也可以是极夜或极昼现象，昨天的动态评论区也给了一些开服操作建议，以及 “永夜”对游戏机制的影响。

“水友联机”群的第31个水服主题叫“泰拉永夜抄”，用tshock开的服，里面有个配置可以将时间锁定在夜晚，开服后进游戏发现时间停留在00:00不走，死掉的npc不会再来，月相不会更新，一直是夜晚还真是影响很大，于是写了一个插件。

插件部分

**插件名字**：**LongNight**

**开源地址**：https://gitee.com/hufang360/TShockLongNight/releases/v1.0.0.1

**插件功能**：04:25~04:29期间会进行永夜判定，会出现连续8个夜晚，这期间称为“永夜”，永夜之后是一个白天，然后再次进入“永夜”。
“永夜”期间会更换月相和渔夫任务，但是不会结束血月。

“永夜”轮替全员都会收到提示，“『 永夜 · 其一 』”~“『 永夜 · 其八 』”之类，进入白天会提示是“『 永夜 · 终章 』”。

服主可以输入指令 /longnight help 指令进行管理，目前插件不会保存配置，服务器重启后永夜及相关配置将使用默认值。
