# 在CentOS8.0上运行 forge-1.18.2-40.1.76

> [!NOTE] 本文原载于 Bilibili 专栏
> [阅读原文](https://www.bilibili.com/read/cv18573392/) · 2022-09-13
> 成文较早，文中的版本号和命令可能已经过时，请结合实际情况判断。

前些日子，尝试在CentOS8.0上运行1.18.2的mc服务器，1.18要求jdk17，且启动forge的命令行参数跟1.16不一样， 吃了些苦头，甚至有些气馁，好在后面还是解决了，所以记录下。

## 下载安装forge

和1.16.5一样，先从forge官网下载安装包，然后再安装，目前1.18.2 对应的是40.1.76，输入以下命令：

```bash
mkdir -p /root/mc/1.18.2/client/
cd /root/mc/1.18.2/client/
wget https://maven.minecraftforge.net/net/minecraftforge/forge/1.18.2-40.1.76/forge-1.18.2-40.1.76-installer.jar
java -jar forge-1.18.2-40.1.76-installer.jar nogui --installServer
```

创建文件夹，并切换工作目录，然后下载.jar格式的安装包

## 安装jdk17

输入 "./run.sh" 然后敲Enter键，尝试启动服务器，结果提示“错误: 找不到或无法加载主类 @user\_jvm\_args.txt”，如下图：

![[cv18573392-05.webp]]

输入 "java -version" 然后敲Enter键，查询java版本，如下图：

![[cv18573392-06.webp]]

查询显示java版本是1.8.0\_312，因为1.18需要java17，因此要安装jdk17。

输入 "yum search java\*" 然后敲Enter键，查询可供安装的java版本，如下图：

![[cv18573392-07.webp]]

“java-17-openjdk.x86\_64"是安装目标

![[cv18573392-08.webp]]

输入下面的指令进行安装

```bash
yum install java-17-openjdk.x86_64
```

## 更优雅的开服方式

个人习惯将服务器和世界分开，所以调整了开服启动脚本，

输入下面的指令创建 run.sh 启动脚本：

```bash
cd /root/mc/1.18.2/
touch run.sh
chmod +x run.sh
```

将下面的内容，写入刚才创建的 run.sh 脚本中：

```bash

current_dir=$(cd `dirname $0`; pwd)
client_root="${current_dir}/client/libraries/"
server_root="${current_dir}/doc/"

if [ ! -d "${server_root}" ];then
 mkdir "${server_root}"
fi
cd "${server_root}"

current_dir=$(cd `dirname $0`; pwd)
/etc/alternatives/jre_17/bin/java \
 -Xmx4G \
 -Xms4G \
 -p "${client_root}"cpw/mods/bootstraplauncher/1.0.0/bootstraplauncher-1.0.0.jar:"${client_root}"cpw/mods/securejarhandler/1.0.3/securejarhandler-1.0.3.jar:"${client_root}"org/ow2/asm/asm-commons/9.2/asm-commons-9.2.jar:"${client_root}"org/ow2/asm/asm-util/9.2/asm-util-9.2.jar:"${client_root}"org/ow2/asm/asm-analysis/9.2/asm-analysis-9.2.jar:"${client_root}"org/ow2/asm/asm-tree/9.2/asm-tree-9.2.jar:"${client_root}"org/ow2/asm/asm/9.2/asm-9.2.jar \
```

此时出现了两个 run.sh，注意区分下哦：

/root/mc/1.18.2/run.sh   （新的启动脚本）

## java多版本共存

事情还没完，当我去启动1.12.2的服务器时，报错了，乖乖，1.12.2不能在jdk17下面运行~~~~

![[cv18573392-18.webp]]

意味这要让 jdk1.8.0 和 jdk17 共存，经过一些摸索，只要再次安装下jdk1.8.0基，本就能解决问题了。

输入 "yum install java" 或者 "yum install java-1.8.0-openjdk.x86\_64 "，然后敲Enter键：

![[cv18573392-19.webp]]

安装完成后，再次查询java版本，如下图：

![[cv18573392-20.webp]]

此时服务器上先安装了jdk17，后安装了jdk1.8.0，安装的就是最后的java版本，由于jdk1.8.0比较常用且稳定，故用这个版本作为服务器的基准。因为没有卸载jdk17，jdk17相关的文件还在服务器上，只是没有加到环境变量里

在我服务器上jdk17位于 “/etc/alternatives/jre\_17/bin/java”

因此启动脚本的java改成了“/etc/alternatives/jre\_17/bin/java”，就是调用jdk17启动服务器了（上文的脚本已经改过了）。

## 卸载jdk

想卸载jdk17 怎么办？

输入下面的指令查询安装情况：

```bash
sudo rpm -qa | grep java
```

如下图：

![[cv18573392-21.webp]]

使用 "rpm -e --nodeps xx" 指令卸载对应内容，例如：

```bash
sudo rpm -e --nodeps java-17-openjdk-17.0.1.0.12-2.el8_5.x86_64
sudo rpm -e --nodeps java-17-openjdk-headless-17.0.1.0.12-2.el8_5.x86_64
```
