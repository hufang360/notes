# cs1.6联机私服

> [!NOTE] 本文原载于 Bilibili 专栏
> [阅读原文](https://www.bilibili.com/read/cv53068959/) · 2026-09-18

先插眼，换地图加机器人还没学会，以后补上。

## 快速上手

```yaml
# 联机
# 启动cs1.6，主界面按下波浪号键（键盘左上角）
# 输入 connect <服务器ip>

# 查看可用地图
# docker exec -it cs16-server ls /hlds/cstrike/maps

# 自定义服务器名称
# docker exec cs16-server sed -i 's/hostname ".*"/hostname "hf的炙热沙城"/' /hlds/cstrike/server.cfg

services:
  cs16-server:
    image: archont94/counter-strike1.6:latest
    container_name: cs16-server
    ports:
      - 27015:27015/udp
      - 27015:27015
      - 8880:80
    environment:
      - TZ=Asia/Shanghai
      - SV_LAN=1          # 开启局域网联机，默认0
      - MAP=de_dust2
      - MAXPLAYERS=32
```

- 镜像大小，大概1个G
