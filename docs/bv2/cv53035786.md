# 饥荒联机版：多人联机服务器搭建 Docker篇

> [!NOTE] 本文原载于 Bilibili 专栏
> [阅读原文](https://www.bilibili.com/read/cv53035786/) · 2026-09-16

Respect jamesits/dst-server 🫡！

## 快速上手

`.docker-compose.yml`

```yaml
services:
  dst-server:
    image: jamesits/dst-server:latest-slim
    container_name: dst-server
    restart: "on-failure:5"                # 失败后重启（默认重启 5 次）
    stop_grace_period: 1m
    environment:
      - TZ=Asia/Shanghai
      - DST_SERVER_ARCH=amd64
      - DST_CLUSTER_TOKEN=${DST_CLUSTER_TOKEN}
    ports:
      - "10999-11000:10999-11000/udp"
      - "12346-12347:12346-12347/udp"
    volumes:
      - ./data/dst_server:/opt/dst_server  # 饥荒开服工具
      - ./data/dst_data:/data              # 服务器配置
```

`.env`

```plaintext
# 申请令牌
# https://accounts.klei.com/account/game/servers?game=DontStarveTogether

DST_CLUSTER_TOKEN=pds-g^KU_xdsfasdfasdfsadfasfasfsadfsad
```

- `jamesits/dst-server:latest-slim` ，不含饥荒开服工具，但启动时会自动下载。
- `./data/dst_server`，开服工具，yml同目录下的 data 文件夹里。
- `./data/dst_data`，服务器配置。容器启动时，发现文件夹不存在，会自动释放出一份默认配置。

启动容器

```bash
# 启动容器
docker compose up -d

# 查看容器日志
docker logs -f dst-server
```

首次启动会报错，但容器会自动重启，然后自动下载开服工具。

## cluster.ini

编辑：`./data/dst_data/DoNotStarveTogether/Cluster_1/cluster.ini`

```bash
cd ./data/dst_data/DoNotStarveTogether/Cluster_1
vim cluster.ini
```

参考：

```ini
; 以下是所有你可以修改的服务器配置项。

[NETWORK]
cluster_language = zh                 ; 服务器语言 中文=zh, 繁体=zht, 英文=en
; 请更改名称和描述！
cluster_name = hf和他的小伙伴们        ; 服务器名字
cluster_description = 这家伙很懒，什么都没写~   ; 服务器介绍
cluster_password = 你的密码            ; 服务器密码
offline_cluster = false               ; 是否离线模式（局域网离线游戏）
lan_only_cluster = false              ; 是否仅限局域网
whitelist_slots = 1                   ; 白名单玩家预留坑位数量
cluster_intention = social            ; 游戏风格 社交=social, 合作=cooperative, 竞争=competitive, 疯狂=madness
autosaver_enabled = true              ; 是否自动保存
;tick_rate = 30                       ; 服务器 tick 频率（一般不改）

[GAMEPLAY]
game_mode = endless                   ; 游戏模式 生存=survival, 无尽=endless, 荒野=wilderness
max_players = 8                       ; 最大人数
pvp = false                           ; 是否开启pvp
pause_when_empty = true               ; 服务器无人时，自动暂停
vote_kick_enabled = false             ; 投票踢人

[STEAM]
steam_group_only = false              ; 是否只允许 Steam 组内成员加入
steam_group_id = 0                    ; Steam 组 ID
steam_group_admins = false            ; 是否让 Steam 组管理员成为服务器管理员

[MISC]
console_enabled = true                ; 是否开启控制台
max_snapshots = 6                     ; 最大快照数，决定了可回滚的天数

; ====================================================================
; 停止！除非你知道自己在做什么，否则不要修改下面的配置。
; ====================================================================
; 这部分一般不改
[SHARD]
shard_enabled = true                  ; 是否开启分片（洞穴/地面分离）
bind_ip = 127.0.0.1                   ; 分片绑定 IP
master_ip = 127.0.0.1                 ; 主分片 IP
master_port = 10998                   ; 主分片端口
cluster_key = 你自己的密钥            ; 分片通信密钥
```

请修改 cluster_name、cluster_password，以保证在大厅能找到你的服务器。

## mod

只需将mod的创意工坊id填入对应文件即可，开服时会自动下载。

mod会下载到 `.data/dst_data/ugc/content/322330` 目录下。

```bash
cd ./data/dst_data/DoNotStarveTogether/Cluster_1

vim mods/dedicated_server_mods_setup.lua
vim Master/modoverrides.lua
vim Caves/modoverrides.lua
```

dedicated_server_mods_setup.lua

```lua
ServerModSetup("378160973")  -- Global Positions
ServerModSetup("1185229307")  -- Epic Healthbar
ServerModSetup("2189004162")  -- Insight (Show Me+)
```

modoverrides.lua。一行ServerModSetup，对应一行`["workshop-xx"]`。Caves跟Master一样。

```lua
return{
["workshop-378160973"]={configuration_options={},enabled=true},
["workshop-1185229307"]={configuration_options={},enabled=true},
["workshop-2189004162"]={configuration_options={},enabled=true},
}
```

## 连接

一种是游戏大厅搜索，如果你有给服务器命名，搜名字就能找到。找不到，要么是没开成功，要么是开服工具版本太老，可以通过第三方网站检查服务器是否在线：https://dstserverlist.appspot.com

一种是用指令连接，如果你是云服务器，有公网ip，或者是开在自己电脑上。

主界面按 ~键，调出控制台，输入指令，并敲下Enter键执行。~键，波浪号键 一般位于键盘左上角，在ESC键的下方，Tab键的上方，数字键1的左边；

```bash
c_connect("服务器ip",10999)
c_connect("服务器ip",10999,"密码")

# 如果是开在自己电脑上
c_connect("127.0.0.1",10999)
```

## 关于镜像

jamesits/dst-server镜像，docker hub上的pull次数超500k。由于饥荒还在更新，最近一次是上个月，`nightly` 镜像也不能用。所以是`latest-slim` 。

```plaintext
# 镜像tag
- nightly，1年前更新，2.93 GB，含饥荒开服工具(v677386) 和 steamcmd
- latest，4年前更新，2.01 GB，含饥荒开服工具(v506376) 和 steamcmd
- latest-slim，4年前更新，58.16 MB，不含饥荒开服工具，带 steamcmd

# 几个关键目录
/opt/steamcmd     # steamcmd
/opt/dst_server   # 饥荒开服工具
/opt/dst_default_config  # 一份服务器配置
```

如果你用的是 latest 或 nightly 镜像，可能会遇到`0x6`错误，导致开服工具始终为旧版本：

```plaintext
app_update 343050
 Update state (0x3) reconfiguring, progress: 0.00 (0 / 0)
Error! App '343050' state is 0x6 after update job.
quit
Error on line 56; RET 8.          # 镜像 entrypoint 的 ERR trap
```

删掉这个 acf即可。

```bash
docker exec dst-server rm -rf /opt/dst_server/steamapps/appmanifest_343050.acf
```

## 控制台

终端侧的控制台 是否可用？

这个方案（supervisord 托管）只能看日志，不能当控制台用。

推荐做法：用游戏内的控制台：

```bash
# 把自己设成管理员
# 不熟悉指令的，可以手动编辑
vim data/server/DoNotStarveTogether/Cluster_1/adminlist.txt

# 写入你的 Klei 用户 ID（形如 KU_xxxxxxxx）
# 怎么查：进游戏后按 ~ 打开客户端控制台，输入
print(ThePlayer.userid)

# 重启容器
docker restart dst-server

# 进游戏后按 ~ 打开控制台，按一下 Ctrl 切到远程命令模式
c_listallplayers()

# 满状态，可同时复制粘贴这3行
c_sethunger(1)
c_setsanity(1)
c_sethealth(1)
```

很不幸，镜像里的steamcmd不支持mac，准确来说是不支持arm。

```plaintext
steamcmd.sh[1]: Starting  /root/.local/share/Steam/steamcmd/linux32/steamcmd
Redirecting stderr to '/root/.local/share/Steam/logs/stderr.txt'
Logging directory: '/root/.local/share/Steam/logs'
[  0%] Checking for available updates...
[----] Verifying installation...
UpdateUI: skip show logo

Loading Steam API...[0m/root/.local/share/Steam/steamcmd/steamcmd.sh: line 86:    27 Segmentation fault         $DEBUGGER "$STEAMEXE" "$@"
```

用不了steamcmd，就用DepotDownloader。看到一个受欢迎的镜像，但是长时间没更新，在ai的帮助下我打了一个DepotDownloader的镜像。

`docker-compose.yml`

```yaml
services:
  depotdownloader:
    image: hufang360/depotdownloader
    profiles: ["tools"]
    volumes:
      - ./data/dst_server:/steam
    command: >
      -app 343050 -os linux -osarch 64 -branch public -dir /steam -validate

  dst-server:
    image: jamesits/dst-server:latest-slim
    platform: linux/amd64                  # arm上必须写
    container_name: dst-server
    restart: "on-failure:5"                # 失败后重启（默认重启 5 次）
    stop_grace_period: 1m
    ports:
      - "10999-11000:10999-11000/udp"
      - "12346-12347:12346-12347/udp"
    environment:
      - DST_SERVER_ARCH=amd64
      - STEAMCMD_PATH=/bin/true            # 禁用steamcmd
      - DST_CLUSTER_TOKEN=${DST_CLUSTER_TOKEN}
    volumes:
      - ./data/dst_server:/opt/dst_server  # 饥荒开服工具
      - ./data/dst_data:/data              # 服务器配置
```

`.env `

```bash
# 申请令牌
# https://accounts.klei.com/account/game/servers?game=DontStarveTogether

DST_CLUSTER_TOKEN=pds-g^KU_xdsfasdfasdfsadfasfasfsadfsad
```

启动服务器

```bash
# 首次下载服务端，后面更新也这样
docker compose run --rm depotdownloader
chmod +x ./data/dst_server/bin64/dontstarve_dedicated_server_nullrenderer_x64

# 启动
docker compose up -d

# 查看日志
docker logs -f dst-server
```
