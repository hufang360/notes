# 关于本站

## 这是什么

一个 Markdown 笔记仓库。内容主要是三类：

- **软件** —— 工具、命令行、配置备忘
- **游戏** —— 开服、插件、Docker 化
- **运维** —— 服务器排障、部署、踩坑

写下来的第一目的是给自己回查用 —— 同一个坑不想踩第二遍。如果顺带能帮到你，那更好。

## 技术实现

| 环节 | 用了什么 |
| --- | --- |
| 写作 | [Obsidian](https://obsidian.md)，仓库根目录就是 vault |
| 构建 | [VitePress](https://vitepress.dev)，把 Markdown 生成静态站 |
| 部署 | GitHub Actions → GitHub Pages |
| 源码 | [github.com/hufang360/notes](https://github.com/hufang360/notes) |

因为是纯静态站，没有后端也没有数据库，所以：

- 没有评论功能（想讨论请去仓库提 issue）
- 搜索是在浏览器里做的，索引随站点一起分发

## 内容约定

- 笔记之间用 `[[双链]]` 互相关联
- 命令都标注了验证过的环境（默认 Debian / Ubuntu）
- **不保证适用于你的环境**，执行前请先看懂

> [!WARNING]
> 这里没有「一键脚本」。所有命令请你先读懂再执行。
> 我不会为任何因照抄本笔记造成的损失负责。

## 关于隐私

这个仓库是公开的，所以有两道防线：

1. 真正敏感的内容（密码、密钥、服务器资料）放在 `private/` 目录，该目录已在 `.gitignore` 中，**从未被提交**
2. 提交前有 `gitleaks` 钩子扫描，防止手滑把密钥写进正文

> [!IMPORTANT]
> `draft: true` 只让笔记**不出现在网站上**，文件本身仍在仓库里，别人 clone 就能看到。
> 它适合「写了一半不想给人看」，不适合「藏密码」。

## 发现错误

笔记里的命令和版本信息会过时。如果你发现哪条不对，欢迎到 [Issues](https://github.com/hufang360/notes/issues) 指出来，或者直接 PR。

每篇笔记底部有「在 GitHub 上编辑此页」的链接，改起来很快。
