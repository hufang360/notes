# 关于本站

## 这是什么

我的笔记仓库。写下来的第一目的是**给自己回查** —— 同一个坑不想踩第二遍。
如果顺带能帮到路过的同好，那更好。

内容分三块：

- [[bv1|腐竹计划]] —— Terraria / TShock 开服，写得最系统的一组
- [[bv2|游戏笔记]] —— Starbound、tModLoader、饥荒、Minecraft 的杂记
- [[terraria|泰拉瑞亚]] —— TL Pro 材质包制作与转换

笔记是沉淀。有用就行，不求多。

## 时效性

这批笔记跨了 2020 ~ 2026 年。**看的时候先看日期**：

- 开服相关的笔记，思路通常仍然有效，但命令和版本号会过时
  （比如 TShock 的运行时从 mono 换到了 .NET 6，又准备换 .NET 9）
- 版本更新日志、资源包制作这类，只当历史记录看
- 每篇顶部有原文日期和「成文较早」的提示

> [!WARNING]
> 这里没有「一键脚本」。所有命令请你先读懂再执行。
> 我不为任何因照抄本笔记造成的损失负责。

## 技术实现

| 环节 | 用了什么 |
| --- | --- |
| 写作 | [Obsidian](https://obsidian.md)，仓库根目录就是 vault |
| 构建 | [VitePress](https://vitepress.dev)，把 Markdown 生成静态站 |
| 部署 | GitHub Actions → GitHub Pages |
| 源码 | [github.com/hufang360/notes](https://github.com/hufang360/notes) |

因为是纯静态站，没有后端也没有数据库，所以：

- 没有评论功能，想讨论请去仓库提 issue
- 搜索是在浏览器里做的，索引随站点一起分发

## 内容怎么组织的

**目录就是导航。** `docs/` 下的一级目录就是一个节点，里面的笔记平铺，不再往下分层。

链接用 Obsidian 的写法：

| 写法 | 效果 |
| --- | --- |
| `[[名字]]` | 链接到另一篇，显示文字自动取对方标题 |
| `[[名字\|显示文字]]` | 带别名的链接 |
| `![[图片.webp]]` | 嵌入图片 |
| `> [!note]` 等 | 提示框 |
| `%%注释%%` | 构建时删掉，网站上不存在 |

## 怎么写一篇笔记

每篇开头有一段 frontmatter：

```yaml
---
title: 笔记标题
tags: [terraria, tshock]
order: 10         # 同级排序，小的在前
draft: false      # true = 不进构建产物
---
```

图片统一放 `docs/public/assets/`，粘贴进 Obsidian 会自动落到那里。

## 关于隐私

这个仓库是公开的，所以有两道防线：

1. 真正敏感的内容（密码、密钥、服务器资料）放在 `private/` 目录，该目录已在 `.gitignore` 中，**从未被提交**
2. 提交前有 `gitleaks` 钩子扫描，防止手滑把密钥写进正文

> [!IMPORTANT]
> `draft: true` 只让笔记**不出现在网站上**，文件本身仍在仓库里，别人 clone 就能看到。
> 它适合「写了一半不想给人看」，不适合「藏密码」。

## 发现错误

笔记里的命令和版本信息会过时。如果你发现哪条不对，欢迎到 [Issues](https://github.com/hufang360/notes/issues) 指出来，或者直接 PR。

每篇笔记底部有「在 GitHub 上编辑此页」的链接，改起来很快。
